# 对拍

中文名：**对拍** · 前缀 `duet` · 端口 **7800**

## 骨架（新骨，不是闸对/缝包换皮）

**左轨装载 → 右轨装载 → 同键对齐落差 → 单边悬账 → 对拍结论**

| 对比 | 闸对 | 缝包（已弃） | **对本仓** |
| --- | --- | --- | --- |
| 拓扑 | 单流入→在途→成物 | 单流入→在途→成物 | **双轨独立装载→键对齐** |
| 在途态 | 开腿账 | 拼缝账 | **无开腿/拼缝；悬账是对齐后单边** |
| 产物 | 行程账 | 整件账 | **对齐差 + 对拍结论** |
| 旁路名 | 旁路匣 | 旁路匣 | **悬账单（命名与语义都不同）** |

皮：支付渠道回执 vs 核心记账。去皮：**双源键对齐管道**。禁止做成收银 CRUD、报表看板、工单系统。

## 页面（真翻页，每模块独立 HTML）

对拍台 · 左轨流水 · 右轨流水 · 对齐差表 · 悬账单 · 悬账升格 · 对拍结论 · 源登记 · 轨规

## 悬账升格回正（本仓已落地，非空桩）

超时悬账须择定升格形态，两种形态命运分开：

| 形态 | 悬行去向 | 自动对齐 | 补齐对边后 |
| --- | --- | --- | --- |
| 旁路 | 悬行改「已升格」写入**升格旁路账册**（终态） | 不再参与 | 只入账，仍不自动对齐 |
| 影子 | 悬行改「已升格」写入**影子草稿**（只读） | 暂不参与 | 同事务原子晋升回现行对齐 |

- 悬账单与对齐差同票：升格时改悬账状态与改对齐差票（差型 `升格旁路` / `升格影子`）同事务、同成败；
- 超时后按业务键读现行悬账是否仍可对齐须可区分：`GET /api/悬账升格/读?业务键=...`（或 `/api/悬账升格/{业务键}`）返回 `悬龄秒 / 状态 / 旁路键 / 影子键 / valid / 可自动对齐 / 可晋升`；
- 扫描：`POST /api/悬账升格/扫描`（`{超时秒, 形态, 形态映射?}`）；晋升：`POST /api/悬账升格/晋升`；人工回正：`POST /api/悬账升格/人工回正`；补齐：`POST /api/悬账升格/补齐对边`；
- 并发：写路径共用写锁 + `BEGIN IMMEDIATE`，悬账状态 CAS 迁跃；升格与补齐/人工回正并发只落一边，不会「升格后又对齐」双落；
- 超时口径：轨规 `悬账超时秒`（默认 60）、`悬账升格形态`（默认 `影子`）；反复跑对齐不清零悬龄。
